에듀파인 자동 품의 — 처음 설정
1. 안내·동의2. Claude API 키3. 소속 교육청4. 시작

이 프로그램은 선생님 대신 Claude(AI)가 업무포털·K-에듀파인 화면을 보고 마우스와 키보드를 움직여 품의를 작성합니다.

이 프로그램은 동쌤(김동은 선생님)이 만든 교사 제작 도구이며, 교육청·한국교육학술정보원의 공식 프로그램이 아닙니다. 선생님의 설정과 기록은 이 PC에만 저장되며 제작자에게 전송되지 않습니다.

Claude를 쓰려면 본인 API 키가 필요합니다. (사용한 만큼 Anthropic에 요금이 청구됩니다)

  1. console.anthropic.com 에 가입·로그인
  2. Billing에서 결제 수단 등록 후 크레딧 충전 (예: 5달러)
  3. API Keys → Create Key 로 키를 만들고 복사 (sk-ant- 로 시작)
키는 이 PC의 윈도우 계정으로 암호화해 저장합니다.

준비 완료! 처음에는 연습 모드로 한 번 실행해 보세요. 실제 에듀파인과 비슷한 모의 화면에서 Claude가 어떻게 움직이는지 볼 수 있고, 실제 시스템에는 아무것도 남지 않습니다.

실제로 쓸 때는 업무용 PC에 K-에듀파인 보안 프로그램(인증서 모듈)이 설치되어 있어야 합니다.

최근 품의 (이 PC에서 작성한 것)
도움말
  1. 품의 내용을 한두 줄로 적고 [Claude로 품의 초안 만들기]를 누릅니다.
  2. 초안의 제목·품목·금액·예산 단서를 확인·수정합니다. 노란 상자는 Claude가 추정한 값입니다.
  3. [에듀파인에 자동 작성]을 누르면 새 브라우저 창이 열립니다. 작업 중에는 그 창을 건드리지 마세요.
  4. 인증서 암호 입력이나 예산 선택이 애매할 때는 "Claude가 선생님께 요청합니다" 창이 뜹니다.
  5. 저장이 끝나면 결재요청 최종 승인 창이 뜹니다. 브라우저 화면을 확인하고 승인하세요.

잘 안 될 때

  • "브라우저 창이 이미 열려 있습니다" → 자동 작성용 브라우저 창을 닫고 다시 시도
  • 보안 프로그램 설치 안내가 뜸 → 안내대로 설치 후 다시 실행
  • 메뉴를 못 찾음 → [설정] › 우리 학교 참고사항에 메뉴 위치를 적어 주세요
  • API 연결 실패 → 학교 방화벽에서 api.anthropic.com 이 막혀 있는지 정보담당자에게 문의
  • 문제 보고 시 [설정] › 로그 폴더의 app.log 를 첨부해 주세요 (스크린샷 폴더는 업무 화면이 담겨 있으니 공유 주의)
