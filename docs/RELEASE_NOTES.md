## 에듀파인 자동 품의

**제작자: 동쌤(김동은 선생님)**

**선생님들은 아래 `EdufineAutoPumui-Setup-*.exe` 를 내려받아 설치하세요.**
(설치가 막힌 PC는 `EdufineAutoPumui-portable-*.zip` 을 압축 풀어 `EdufineAutoPumui.exe` 실행)

- 관리자 권한 없이 설치됩니다. 이미 설치하셨다면 그대로 덮어 설치하면 되고, 설정·기록은 유지됩니다.
- "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 내려받은 파일이 변조되지 않았는지 `SHA256SUMS.txt`의 해시와 비교할 수 있습니다.
- 처음 실행하면 설정 마법사가 안내합니다. Claude API 키는 선생님 본인 것으로 발급해 주세요(사용 요금은 각자의 키에 청구됩니다).
- 자세한 사용법: [사용설명서](https://github.com/DONGSSAM-CLASS/dongssam-s-vibecoding/blob/v1.0.1/docs/사용설명서.md)
