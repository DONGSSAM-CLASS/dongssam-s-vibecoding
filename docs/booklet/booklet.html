SETUP · 처음 한 번

확장 프로그램 설치와 로그인

  1. Google Chrome을 엽니다엣지·웨일 등 다른 브라우저와 휴대폰은 지원하지 않습니다.
  2. Claude in Chrome 설치크롬 웹 스토어에서 'Claude in Chrome'을 검색해 Chrome에 추가를 누릅니다.
  3. 유료 계정으로 로그인Pro·Max·Team·Enterprise 플랜의 Claude 계정으로 로그인합니다.
  4. 툴바에 고정주소창 오른쪽 퍼즐 조각 아이콘 → Claude 옆 압정을 눌러 고정합니다.
  5. 업무포털 접속 확인이 크롬으로 업무포털에 한 번 접속해, 인증서 로그인용 보안 프로그램이 설치되어 있는지 확인합니다.
팁 — 업무포털 주소를 즐겨찾기에 등록해 두면 매번 찾지 않아도 됩니다.

04지시문 전문
SHORTCUT · 처음 한 번

지시문을 /품의 바로가기로

  1. Claude 창 열기오른쪽 위 Claude 아이콘을 눌러 옆 창(사이드 패널)을 엽니다.
  2. 지시문 복사아래 QR 코드나 주소로 웹 안내서를 열고, 지시문 상자 오른쪽 위 복사 버튼을 누릅니다. PDF에서 복사하면 줄바꿈이 흐트러질 수 있습니다.
  3. 바로가기로 저장Claude 창 입력칸에 붙여 넣고 바로가기(shortcut)로 저장합니다. 이름은 품의. 저장한 바로가기는 입력칸에 /를 치면 나오고, 확장 프로그램 설정에서 고칠 수 있습니다.
  4. 우리 학교 참고사항 적기지시문 맨 아래에 메뉴 위치 등 우리 학교·교육청만의 특징을 적어 두면 Claude가 그대로 따릅니다.

FAQ

증상별 해결 방법

증상해결
Claude가 메뉴를 못 찾음지시문 맨 아래 '우리 학교 참고사항'에 메뉴 위치를 적어 바로가기를 고쳐 저장합니다.
인증서 창이 안 보이거나 보안 프로그램 설치 안내가 뜸이 크롬에서 업무포털에 직접 한 번 로그인해 보안 프로그램을 먼저 설치합니다.
"이 작업은 할 수 없습니다"처럼 멈춤Claude in Chrome은 구매·금융 거래 등 일부 동작을 아예 막습니다. 그 단계는 직접 클릭합니다.
금액이 틀리게 들어감초안 단계에서 금액을 고친 뒤 다시 진행합니다. 저장 전 화면의 요구금액을 꼭 확인합니다.
사용량 한도 안내가 뜸유료 플랜 사용량 한도에 닿은 것입니다. 잠시 뒤 다시 시도합니다.

SECURITY & RESPONSIBILITY

정보보안과 책임

정보보안 지침 확인작업 중 화면 내용이 Claude(Anthropic)로 전송됩니다. 소속 교육청의 정보보안 지침(외부 AI 서비스·업무 자동화)을 먼저 확인하세요.
인증서 암호는 직접인증서 암호는 선생님이 직접 입력하세요. Claude에게 채팅으로 암호를 알려 주지 마세요.
상신 전 직접 확인결재요청·상신 전에 화면의 값을 직접 확인하세요. 품의 내용의 책임은 기안자에게 있습니다.
비공식 교사 제작 자료이 안내서와 지시문은 동쌤(김동은 선생님)이 만든 교사 제작 자료이며, 교육청·한국교육학술정보원·Anthropic의 공식 자료가 아닙니다.
