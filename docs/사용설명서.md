# 에듀파인 자동 품의 — 선생님용 사용설명서

**제작자: 동쌤(김동은 선생님)**

한두 줄로 품의 내용을 적으면 Claude(AI)가 품의서 초안을 만들고,
업무포털 인증서 로그인부터 K-에듀파인 품의 작성·저장, 결재요청(기안)까지 대신 진행해 주는 프로그램입니다.

---

## 1. 준비물

| 준비물 | 설명 |
|---|---|
| 업무용 Windows PC | Windows 10/11. K-에듀파인에 평소 접속하던 PC (보안 프로그램·인증서가 설치된 PC) |
| Chrome 또는 Edge | 둘 중 하나만 있으면 됩니다 (Edge는 Windows에 기본 설치) |
| Claude API 키 | 선생님 본인 명의로 발급. 아래 3장 참고 |

## 2. 설치

1. 배포 페이지에서 **`EdufineAutoPumui-Setup-버전.exe`** 를 내려받아 실행합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누르세요. (교사가 만든 프로그램이라 인증서 서명이 없어서 뜨는 안내입니다)
   - 관리자 권한이 필요 없습니다.
2. 설치가 끝나면 바탕화면의 **에듀파인 자동 품의** 아이콘으로 실행합니다. 브라우저에 프로그램 화면이 열립니다.

> 설치가 막힌 PC라면 `EdufineAutoPumui-portable-버전.zip` 을 받아 압축을 풀고 `EdufineAutoPumui.exe` 를 실행해도 됩니다.

## 3. Claude API 키 받기 (처음 한 번)

1. <https://console.anthropic.com> 에 가입·로그인
2. **Billing(결제)** 에서 카드 등록 후 크레딧 충전 (처음엔 5달러 정도면 충분)
3. **API Keys → Create Key** → 이름 입력 → 만들어진 키(`sk-ant-`로 시작)를 복사
4. 프로그램 첫 화면의 **처음 설정** 2단계에 붙여넣고 **연결 테스트** → "연결 성공"이 나오면 다음

- 키는 이 PC의 Windows 계정으로 암호화해 저장됩니다. 다른 사람과 키를 공유하지 마세요.
- 비용은 품의 1건에 대략 1~3달러 수준입니다. (설정에서 **Claude Sonnet 5.5**를 고르면 더 저렴합니다)
- Console의 **Limits** 에서 월 사용 한도를 정해 두면 안심입니다.

## 4. 처음 설정 마법사

처음 실행하면 4단계 안내가 나옵니다.

1. **안내·동의** — 스크린샷 전송, 정보보안 지침, 최종 책임에 대한 세 가지 항목 확인
2. **Claude API 키** — 붙여넣기 → 연결 테스트
3. **소속 교육청** — 업무포털 주소가 자동으로 정해집니다. 인증서가 여러 개면 본인 이름을 적어 두세요.
4. **시작** — 연습 모드가 자동으로 켜집니다.

## 5. 품의 작성하기

1. **품의할 내용**을 적습니다. 예)
   - `기술 수업 롤링볼 재료 우드락 450x450 10장 장당 3000원, 과학 교과활동 예산`
   - `과학실 실험용 비커 500ml 20개, 일회용 장갑 5박스 구입`
2. **[Claude로 품의 초안 만들기]** → 제목·품목·금액·예산 단서·개요가 채워집니다.
   - 노란 상자에 적힌 값은 Claude가 **추정한 값**입니다. 꼭 확인·수정하세요.
   - 품목·금액을 고쳤으면 **[금액 반영해 다시 만들기]** 로 개요를 다시 만드세요.
3. 진행 범위를 고릅니다.
   - **결재요청(기안)까지** — 저장 후 최종 승인 창에서 승인해야만 상신합니다.
   - **저장까지만** — 결재요청은 직접 누릅니다.
4. **[에듀파인에 자동 작성]** → 새 브라우저 창이 열리고 Claude가 진행합니다.
   - **작업 중에는 그 창을 마우스로 건드리지 마세요.**
   - 오른쪽 화면에서 진행 단계(①~⑧), 실시간 화면, 소요시간을 볼 수 있습니다.
   - "Claude가 선생님께 요청합니다" 창이 뜨면 안내대로 처리하고 **[완료]**.
     (예: 인증서 암호를 직접 입력, 예산 행이 애매할 때 고르기)
5. **결재요청 최종 승인** 창 — 브라우저 화면의 값을 확인하고 **[승인하고 상신]** 또는 **[보류]**.

> **처음 한두 번은 꼭 「연습 모드」로 해 보세요.** 실제 에듀파인과 비슷한 모의 화면에서 진행되며 실제 시스템에는 아무것도 남지 않습니다.

## 6. 메뉴

| 메뉴 | 내용 |
|---|---|
| 최근 품의 | 이 PC에서 작성한 품의 목록. **[다시 쓰기]** 로 비슷한 품의를 빠르게 작성 |
| ⚙ 설정 | API 키, AI 모델, 교육청, 인증서 사용자/암호 저장, 기본 진행 범위, 브라우저, 기록 보관 기간, **우리 학교 참고사항**, 브라우저 점검 |
| 도움말 | 사용 순서와 문제 해결 |
| 종료 | 프로그램 종료 (화면을 닫고 20분이 지나도 자동 종료) |

**우리 학교 참고사항**: 교육청마다 메뉴 위치나 버튼 이름이 조금씩 다릅니다.
Claude가 자주 헤매는 지점을 적어 두면 다음부터 그대로 따릅니다.
예) `품의목록은 '학교회계 > 품의관리' 메뉴에 있음`, `예산 선택 후 '적용' 버튼을 눌러야 함`

## 7. 문제 해결

| 증상 | 해결 |
|---|---|
| "자동 작성용 브라우저 창이 이미 열려 있습니다" | 이전에 열린 자동 작성 창을 닫고 다시 실행 |
| "크롬이나 엣지를 실행하지 못했습니다" | 설정 › 사용할 브라우저를 Edge로 바꾸고 **브라우저 점검** |
| 보안 프로그램 설치 안내가 뜸 | 안내대로 설치 후 다시 실행 (업무포털 첫 접속과 같음) |
| 인증서 암호 입력이 안 됨 | 일부 키보드 보안 프로그램이 자동 입력을 막습니다. 요청 창이 뜨면 직접 입력 |
| "Claude API에 연결하지 못했습니다" | 학교 방화벽에서 `api.anthropic.com` 이 막혔을 수 있습니다. 정보담당자에게 문의 |
| "API 키가 올바르지 않습니다" / 크레딧 부족 | Console에서 키·결제 상태 확인 후 설정에서 다시 입력 |
| 메뉴를 못 찾고 헤맴 | [중단] 후 설정 › 우리 학교 참고사항에 메뉴 위치를 적고 다시 실행 |
| 화면을 닫아 버렸음 | 바탕화면 아이콘을 다시 누르면 작업 중이던 화면이 다시 열립니다 |

문제를 알려 주실 때는 **설정 › 로그 폴더**의 `app.log` 를 첨부해 주세요.
`기록 폴더`(runs)에는 업무 화면 스크린샷이 들어 있으니 공유할 때 주의하세요.

## 8. 꼭 지켜 주세요

- 작업 중 화면 스크린샷이 Claude API(Anthropic)로 전송됩니다. **소속 교육청의 정보보안 지침**을 먼저 확인하세요.
- 상신 전 최종 승인은 **반드시 화면을 직접 확인한 뒤** 누르세요. 품의 내용의 책임은 기안자에게 있습니다.
- 이 프로그램은 동쌤(김동은 선생님)이 만든 교사 제작 도구이며, 교육청·한국교육학술정보원의 공식 프로그램이 아닙니다.
- 설정과 기록은 `%LOCALAPPDATA%\EdufineAutoPumui` 에만 저장되며 제작자에게 전송되지 않습니다.
