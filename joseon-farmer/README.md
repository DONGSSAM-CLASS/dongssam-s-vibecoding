# 조선의 농민 — 반 전체가 함께 고르는 실시간 역사 이야기

**대상** 중학교 3학년 · **수업** 15분 · **장면** 4개 (세종 1430 · 1446 → 연산군 1504 · 1504)

학생은 세종 시기와 연산군 시기를 사는 고양 땅의 한 농민 집안 사람이 됩니다.
교사 화면에 장면이 뜨면 학생들이 각자 휴대전화로 고르고, 투표 막대가 실시간으로 쌓이며, 다수의 선택으로 이야기가 이어집니다.
장면마다 사료 퀴즈를 맞히면 **엽전 3닢**이 쌓이고, 학생은 **장터**에서 다음 장면을 버틸 물건(쌀·무명·호미·짚신·약초)을 삽니다.
마지막에는 **우리 반의 선택과 실제 역사**를 나란히 놓고, 핵심 질문에 한 문장으로 답합니다.

| 화면 | 주소 | 쓰는 사람 |
|---|---|---|
| 학생 화면 | `https://프로젝트ID.web.app` (`index.html`) | 학생 휴대전화·태블릿 |
| 교사 화면 | `https://프로젝트ID.web.app/teacher.html` | 교실 TV·프로젝터에 띄운 노트북 |

## 수업 진행 (15분 기준)

| 시간 | 교사 화면에서 누를 것 | 학생이 하는 일 |
|---|---|---|
| 0~2분 | **새 수업 방 만들기** → QR·주소·네 자리 방 번호가 크게 뜸 | QR을 찍고 방 번호와 **별명**으로 입장, 장터에서 첫 물건 구입 |
| 장면마다 약 3분 | **이야기 시작** / **장면 N으로** → 이야기를 소리 내어 읽기 | A·B·C 중 고르기 (마감 전까지 바꿀 수 있음) |
| | **투표 마감 · 결과 보기** → 다수의 선택으로 이야기가 이어짐 | 살림(생명력) 변화 확인, 가진 물건이 있으면 덜 다침 |
| | **사료 퀴즈 열기** → **정답 공개** | 사료를 읽고 답하기. 맞히면 초록빛·폭죽 + 엽전 3닢, 틀리면 흔들림 |
| 13~15분 | **마지막: 우리 반 vs 실제 역사** | 칭호·점수·걸린 시간 확인, 마지막 질문에 한 문장 → 교사 화면에 바로 올라옴 |

- 교사 화면 위쪽에 **남은 수업 시간(15:00)** 이 흐릅니다. 2분 아래로 남으면 깜빡입니다.
- 화면 맨 아래 **[교사 확인용 사실 목록]** 을 펼치면 사건·연도·인물과 "확인 필요" 표시가 있습니다.
- 지어낸 인물(최 노인, 칠복 아범, 순이네, 박 서방, 너의 집안)은 화면에 **가상 인물**로 표시됩니다.
- 끝난 뒤 **같은 방에서 다시 하기**를 누르면 학생들의 엽전·살림이 처음으로 돌아갑니다.

## Firebase 처음 쓰는 선생님을 위한 5단계

> 무료 요금제(Spark)로 충분합니다. 신용카드 등록이 필요 없습니다.
> 한 반 30명이 한 번 하면 읽기 약 5천 회 · 쓰기 약 1천 회로, 하루 무료 한도(읽기 5만 · 쓰기 2만)의 10분의 1쯤입니다.

### 1단계. 프로젝트 만들기 (약 2분)
1. https://console.firebase.google.com 에 학교 수업용 구글 계정으로 들어갑니다.
2. **프로젝트 만들기**(또는 **Firebase 프로젝트 시작하기**)를 누릅니다.
3. 프로젝트 이름에 `joseon-farmer` 처럼 영어로 적습니다. 이름 아래에 회색으로 보이는 **프로젝트 ID**(예: `joseon-farmer-1a2b3`)를 메모해 두세요. 이 ID가 학생 주소가 됩니다.
4. Google 애널리틱스는 **사용 안 함**으로 두고 **프로젝트 만들기**를 누릅니다.

### 2단계. 웹 앱 등록 (약 1분)
1. 프로젝트 첫 화면에서 **`</>`(웹)** 아이콘을 누릅니다.
2. 앱 닉네임에 `조선의 농민`을 적습니다. "Firebase 호스팅도 설정" 칸은 체크해도, 안 해도 됩니다.
3. **앱 등록**을 누르면 `const firebaseConfig = { apiKey: ... }` 로 시작하는 상자가 나옵니다. 이 화면을 그대로 두고 4단계로 갑니다. (나중에 다시 보려면: 톱니바퀴 ⚙ → **프로젝트 설정** → 아래쪽 **내 앱**)

### 3단계. Firestore 켜기 (약 2분)
1. 왼쪽 메뉴 **빌드(Build) → Firestore Database** → **데이터베이스 만들기**.
2. 버전을 묻는다면 **Standard**를 고릅니다.
3. 위치는 **`asia-northeast3 (서울)`** 을 고릅니다. (한 번 정하면 바꿀 수 없습니다.)
4. **프로덕션 모드로 시작**을 고르고 **만들기**를 누릅니다. 보안 규칙은 5단계 배포 때 이 폴더의 `firestore.rules`로 자동으로 바뀝니다.

### 4단계. 설정값 붙여 넣기 (약 1분)
1. 이 폴더의 `public/js/firebase-config.js` 를 메모장으로 엽니다.
2. 2단계 화면의 `firebaseConfig` 중괄호 안 값(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)을 같은 이름 자리에 붙여 넣고 저장합니다.
   ```js
   export const firebaseConfig = {
     apiKey: "AIza....",
     authDomain: "joseon-farmer-1a2b3.firebaseapp.com",
     projectId: "joseon-farmer-1a2b3",
     storageBucket: "joseon-farmer-1a2b3.appspot.com",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcd...",
   };
   ```
   - 이 값은 비밀번호가 아니라 "어느 프로젝트인지" 알려 주는 주소라 화면에 들어가도 괜찮습니다. 데이터는 보안 규칙이 지킵니다.
   - 깜빡하고 비워 두어도, Firebase Hosting 주소로 열면 앱이 설정값을 스스로 읽어 옵니다.

### 5단계. 배포 (처음 약 5분, 다음부터 1분)
**Windows**
1. https://nodejs.org/ko 에서 **LTS** 버전을 설치합니다. (처음 한 번만)
2. 이 폴더의 **`deploy.bat`** 를 두 번 클릭합니다.
3. 프로젝트 ID를 물으면 1단계에서 메모한 ID를 넣습니다.
4. 브라우저가 열리면 같은 구글 계정으로 로그인하고 **허용**을 누릅니다. ("Gemini 사용" 같은 질문이 나오면 아무 쪽이나 골라도 됩니다.)
5. 마지막에 `Hosting URL: https://프로젝트ID.web.app` 이 나오면 성공입니다.

**macOS** 는 터미널에서 `./deploy.sh` 를 실행하면 같은 순서로 진행됩니다.

내용을 고친 뒤에는 `deploy.bat`만 다시 두 번 클릭하면 됩니다.

## 보안 규칙 (`firestore.rules`)

"방 문서 아래 쓰기만, 지우기 불가"로 최소한만 열었습니다.

- 읽고 쓸 수 있는 곳: `rooms/{네 자리 숫자}` 문서와 그 아래 `players`(학생 상태) · `votes`(투표) · `quiz`(퀴즈 답) 세 모음뿐
- 지우기: 누구도 못 함
- 그 밖의 경로: 모두 거부. 없는 방에 쓰기, 엉뚱한 선택지(A·B·C 밖), 너무 긴 별명(10자 초과)·답(150자 초과)도 거부

로그인 없이 쓰는 수업용이라, 코드를 잘 아는 학생이 마음먹으면 방 진행 상태를 건드릴 수는 있습니다. 걱정되면 Firebase **익명 로그인**을 켜고 교사만 방을 바꾸도록 규칙을 좁힐 수 있습니다(요청하면 고쳐 드립니다).

## 폴더 구성

```
joseon-farmer/
├─ public/                 ← 배포되는 화면
│  ├─ index.html           학생 화면
│  ├─ teacher.html         교사 화면
│  ├─ css/style.css        한지 미색 · 먹색 · 단청 붉은색, 배경 무늬, 움직임
│  ├─ js/content.js        장면 4개 · 사료 · 퀴즈 · 장터 물건 · 사실 목록 ← 내용 고칠 때 여기
│  ├─ js/art.js            장면 그림(SVG)
│  ├─ js/student.js · teacher.js · ui.js · firebase.js
│  ├─ js/firebase-config.js  ← 4단계에서 붙여 넣는 곳
│  └─ vendor/qrcode.js     QR 코드 만들기 (MIT)
├─ firestore.rules         보안 규칙
├─ firebase.json           Hosting · Firestore · 로컬 에뮬레이터 설정
├─ deploy.bat / deploy.sh  배포
└─ test/two-students.cjs   교사 1 + 학생 2 동시 접속 자동 점검
```
