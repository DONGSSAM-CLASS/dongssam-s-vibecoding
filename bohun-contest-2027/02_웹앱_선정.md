## 2. 최종 선택: "임시정부·광복군 기록관 연작" 4종

```
[1차시] 임시정부 : 광복을 위한 꿈        ── 임정이 무엇을 했나 (체험·공감)
[2차시] 아직 오지 않은 광복              ── 광복군은 왜 '스스로의 광복'을 원했나 (추리·판단)
[3차시] 역사탐정 프로젝트                ── AI가 말하는 임정·광복군 이야기는 사실인가 (검증)
[4차시] 임시정부 : 새로운 나라를 향해    ── 임정이 설계한 나라는 오늘 어떻게 이어졌나 (계승·실천)
```

### 왜 이 조합이 대상감인가
1. **하나의 서사**: 네 앱이 '임시정부 수립(1919) → 광복군(1940~45) → 광복 → 대한민국(민주공화국)'으로 시간 순서대로 이어집니다. 4차시 앱의 학생 역할이 **'기록관'**이므로 프로젝트 전체를 "기록관 프로젝트"로 묶을 수 있습니다(구체성·일관성).
2. **독립 → 민주를 자연스럽게 포괄**: 대한민국 임시헌장(1919) 제1조 "대한민국은 민주공화제로 함", 현행 헌법(1987) 전문 "3·1운동으로 건립된 대한민국임시정부의 법통과 불의에 항거한 4·19민주이념을 계승하고"가 연결고리입니다. 2027년은 **현행 헌법 개정 40주년**이자 **6월 민주항쟁 40주년**입니다(주제 적합성·시의성).
3. **수상작에 한 번도 없던 단계 = 'AI 검증'**: 기존 수상작은 AI를 **만드는 데** 썼습니다(노래·이미지·영상). 이 수업은 AI가 만든 역사 서술을 **사료로 검증**합니다. "부정확한 기억은 희생을 지운다 → 정확히 기억하는 것이 보훈"이라는 메시지가 독창성의 핵심입니다.
4. **지역 보훈 인프라와 직결**: 번동중이 있는 서울 강북구 수유동 일대에는 **한국광복군 합동묘소, 임시정부 요인 묘역(이시영 등), 국립4·19민주묘지**가 모여 있습니다(북한산 순국선열 묘역). 앱으로 만난 인물을 **걸어서 갈 수 있는 거리에서** 다시 만나는 구조입니다. 2025 '보훈 관련 인프라' 분류와 2026 '보훈 기념일' 주제를 동시에 충족합니다.
   - ※ 각 묘역의 정확한 위치·안장 현황은 답사 전 **현충시설정보서비스**와 강북구청 자료로 반드시 확인하세요.
5. **현장 적용 가능성 최상**: 로그인·설치 없는 웹앱 + QR이므로, 모음집에 실리면 전국 교사가 바로 쓸 수 있습니다. 보훈부가 경진대회를 여는 목적(우수 콘텐츠 발굴·확산)과 정확히 맞습니다.

## 3. 공모 전 앱 보강 체크리스트 (심사 대비)

> 앱 내부를 직접 확인하지 못했으므로, 이미 갖춘 항목은 건너뛰세요.

**모든 앱 공통**
- [ ] 첫 화면이나 정보 버튼에 **출처(사료명·소장처)** 표기 → 역사 정확성 신뢰도
- [ ] **개인정보 미수집** 명시 (이름 입력 시 기기 로컬 저장만 하는지 확인) → 학교 적용 장벽 제거
- [ ] **교사용 안내 1쪽**(플레이 시간, 핵심 장면, 발문, 정답 키) → 모음집 수록용
- [ ] 크롬북·디벗·스마트폰 세로 화면 대응, 저사양·저대역 모드
- [ ] **접근성**: 글자 크기 조절, 대사 자막·읽어주기(TTS), '쉬운 글' 모드 → 특수교육·다문화 학생 포용(2025~2026 보훈부 관심사)
- [ ] 활동 결과를 **캡처·코드로 제출**하는 기능 (예: 엔딩 화면에 '임무 완료 코드' 표시 → 학습지에 기록 → 평가 근거)

**앱별**
- [ ] 아직 오지 않은 광복: 엔딩에 김구의 소회(『백범일지』, "참전할 준비를 한 것도 다 허사") 사료 카드
- [ ] 역사탐정 프로젝트: **임정·광복군 전용 '사건 파일' 세트** 추가. 오류가 일부러 섞인 AI 답변 5개와 검증용 사료 링크(국사편찬위원회 한국사데이터베이스, 공훈전자사료관, 독립기념관 한국독립운동정보시스템 등)를 넣습니다. 학생 계정의 생성형 AI 사용이 필요 없도록 **사전 생성 답변** 방식이면 14세 미만 이용 약관 문제를 피할 수 있습니다.
- [ ] 새로운 나라를 향해: 감사의 편지를 **인쇄·PDF 저장**할 수 있게 → 실제 전달용
- [ ] (선택) 독도네컷을 **'기억네컷'**(임정 요인·광복군과 함께 찍기)으로 바꿔 학교 축제 확산 부스에 사용
