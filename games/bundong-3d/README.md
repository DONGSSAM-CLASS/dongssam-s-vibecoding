# 번동중 퇴마록 (樊洞中 退魔錄)

번동중학교를 배경으로 한 **1인칭 3D 탐험·퇴마 게임**입니다.
학교 곳곳에 숨겨진 **실제 한국사 유물 7점**을 찾아, 유물에 깃든 힘(스킬)으로 학교에 침입한 악령을 정화합니다.

- 브라우저(Chrome·Edge 최신 버전)에서 바로 실행됩니다. 설치할 것이 없습니다.
- 그래픽 엔진: [three.js](https://threejs.org) r169 (`vendor/` 폴더에 포함, MIT 라이선스)
- 모든 텍스처와 소리는 코드로 직접 만들었습니다(외부 이미지·음원 없음).

---

## 실행 방법

| 방법 | 설명 |
|---|---|
| **가장 쉬움** | `dist/bundong3d.html` 파일을 **더블클릭** → 브라우저에서 바로 실행 |
| 개발용 | 이 폴더에서 로컬 서버 실행 후 `index.html` 열기 (예: `npx http-server .` 또는 `python -m http.server`) |

> 노트북에서 느리면 `Esc → 설정 → 그래픽 품질 → 낮음`을 고르세요. 주소 끝에 `?quality=low` 를 붙여도 됩니다.

## 게임 진행

1. **캐릭터 선택** — 남학생/여학생 사진 중 하나를 고르고 이름을 적습니다(명찰에 새겨짐). 고르지 않은 학생은 친구로 등장합니다.
2. **첫 유물** — 등나무 쉼터 꼭대기 단의 오래된 반닫이에서 **사인참사검**을 얻으면 악령이 몰려오기 시작합니다.
3. **단서** — 본관 중앙현관 게시판(역사 선생님의 메모)을 읽으면 지도(`M`)에 나머지 유물의 위치가 표시됩니다.
4. **유물 모으기·악령 정화** — 상자, 연못, 진열장(잠긴 문 → 열쇠), 책장, 약품장, 해시계 받침돌(해가 떠 있을 때만)에서 유물을 찾습니다.
5. **보스전** — 일곱 유물이 모이면 운동장 한가운데 봉인석이 솟아오릅니다. 악령의 우두머리 **어둑시니**는 *쳐다볼수록 커지는* 전설 속 요괴입니다. 시선을 피하며 공격하세요.

진행 상황은 자동 저장되며(브라우저 저장소), 처음 화면의 **이어하기**로 이어서 할 수 있습니다.

## 유물 7점과 스킬

| # | 유물 | 시대·소장 | 게임 속 스킬 |
|---|---|---|---|
| 1 | 사인참사검(四寅斬邪劍) | 조선 · 국립중앙박물관 | 참사검격(베기) / 이십팔수 검기(원거리) |
| 2 | 다뉴세문경(多鈕細文鏡) | 청동기 · 국보, 숭실대 한국기독교박물관 | 조요경 섬광 — 기절 + 숨은 악령 드러냄 |
| 3 | 백제 금동대향로(百濟金銅大香爐) | 백제 · 국보, 국립부여박물관 | 정화의 향 — 지속 정화 구역 + 회복 |
| 4 | 곡옥(曲玉) | 신라 금관 장식 | 생명의 결계 — 보호막 + 회복, 지니면 체력 재생 |
| 5 | 비격진천뢰(飛擊震天雷) | 조선 선조 · 보물 | 던지면 시간차로 터지는 폭발 |
| 6 | 신기전(神機箭) | 조선 세종 · 『국조오례서례』 | 로켓 화살 5발 유도 발사 |
| 7 | 앙부일구(仰釜日晷) | 조선 세종 · 보물, 국립고궁박물관 | 시간의 그림자 — 주변 악령을 느리게 |

유물을 얻을 때마다 역사 설명 카드가 나오고, 가방(`I`) → **유물 도감**에서 다시 읽을 수 있습니다.
요청서의 "곡도"는 신라 금관의 **곡옥(굽은 옥)** 으로 해석해 넣었습니다. 굽은 칼(곡도)을 뜻하셨다면 `js/relics.js`, `js/relicModels.js` 에서 바꿀 수 있습니다.

## 세계·시스템

- **참고 영상 반영**: 운동장 동쪽 끝에서 서쪽(인조잔디 운동장·초록 철망·아파트) → 북쪽(파랑·하양·회색 체크 유리 외벽, "희망과 감동을 주는 번동중학교" 간판, 초록 유리 현관, 둥근 지붕) → 동쪽(주황·노랑 패널 계단탑, 갈색 벽돌 별관, 청록 코트, 태양광 차양) → 남동쪽(등나무 쉼터 계단 스탠드, 소나무, 붉은 벽돌 광장, 흰 낮은 벽, 나무 울타리) 배치와 색을 그대로 따랐습니다. 시작 시각도 영상처럼 맑은 아침(08:20)이며, 타이틀 화면 카메라가 영상과 같은 방향으로 천천히 돌아봅니다.
- **환경**: 인조잔디·우레탄 트랙·벽돌 포장·콘크리트 바닥, 연못(물결 반사·수련), 정원석과 바위, 소나무·느티나무·등나무·잔디·코스모스(바람에 흔들림), 학교 텃밭.
- **실내**: 본관 1층(복도, 과학실, 1학년 1·2반, 중앙현관, 도서실, 역사교실)을 실제로 걸어 다닐 수 있습니다. 미닫이 교실 문, 자동 현관문, 사물함이 열립니다.
- **상호작용**: 반닫이(상자) 열기, 책가방 뒤지기, 사물함, 쑥 캐기·팥 따기(시간이 지나면 다시 자람), 가방 칸 늘리기(튼튼한 책가방), 만들기(팥죽, 부적).
- **날씨**: 맑음 → 흐림 → 비 → 뇌우 → 안개 → 눈이 확률표에 따라 2~5분마다 자연스럽게 섞이며 바뀝니다. 비가 오면 바닥이 젖어 반들거리고, 번개가 치면 그림자 악령이 드러납니다. 메뉴에서 날씨를 고정할 수도 있습니다.
- **낮과 밤**: 하루 길이 6/12/24분(기본 12분). 해와 달이 움직이고 노을, 별, 아파트·교실 창문 불빛, 가로등이 켜집니다. 밤에는 악령이 더 많고 빨라집니다. 앙부일구는 해가 떠 있어야 얻을 수 있습니다.
- **그래픽**: 실시간 그림자(PCF 소프트 섀도), ACES 톤매핑, 블룸(빛 번짐), 하늘을 반사하는 환경맵(금속 유물), 직접 만든 하늘 셰이더(새털구름·적운·별·달), 안개.
- **소리**: 바람·나뭇잎·비·천둥, 낮의 새소리(까치), 밤의 풀벌레, 연못 물소리(위치 소리), 바닥 재질별 발소리(잔디·트랙·벽돌·실내 타일·물), 악령 울음(입체음), 유물 스킬 효과음, 가야금처럼 튕기는 국악 5음 효과음, 보스전 북 장단. 학교에는 바다가 없어 파도 소리 대신 연못 물소리를 넣었습니다.

## 학생 캐릭터

선생님이 주신 남학생·여학생 사진이 캐릭터 선택 화면과 게임 화면 왼쪽 위 얼굴에 그대로 쓰입니다.
3D 몸(내 그림자, 아래를 내려다보면 보이는 다리, 친구 NPC)과 1인칭 팔도 사진 속 교복에 맞췄습니다.

| | 남학생 | 여학생 |
|---|---|---|
| 상의 | 남색 V넥 니트 조끼(회색 두 줄), 흰 긴소매 셔츠 | 남색 V넥 니트 조끼, 흰 셔츠(소매를 접어 체크 안감이 보임), 팔찌 |
| 하의 | 회색 바지, 검정 운동화 | 빨강·남색 체크 치마, 흰 양말, 검정 로퍼 |
| 명찰 | 조끼 왼쪽 가슴에 초록 명찰(입력한 이름이 새겨짐)과 교표 | 같음 |

- 고르지 않은 쪽 학생은 **같은 반 친구 NPC**로 운동장 동쪽 끝에 서 있고, 말을 걸면(`E`) 진행 상황에 맞는 단서를 알려 줍니다.
- **사진 바꾸기**: 캐릭터 선택 화면의 '사진 바꾸기' 버튼(그 컴퓨터 브라우저에만 저장).
- **기본 사진 자체를 바꾸려면**: `assets/players/male.jpg`, `female.jpg`(얼굴만 자른 `male_face.jpg`, `female_face.jpg`는 선택)를 바꾼 뒤
  `node tools/embed-photos.mjs` → `node tools/build-single.mjs` 를 실행합니다.

## Meshy AI로 사실적인 3D 모델 만들기

학생 캐릭터와 유물 7점을 Meshy AI로 만든 실사풍 3D 모델(GLB)로 바꿀 수 있습니다. 게임은 GLB가 있으면 자동으로 그 모델을 쓰고, 없으면 코드로 만든 모델을 씁니다.

**준비 (한 번만)**
1. Meshy 웹사이트에 로그인 → API 메뉴에서 **API 키** 발급 (Meshy MCP·API는 계정 비밀번호가 아니라 이 키로 작동합니다)
2. 키는 채팅이나 코드에 붙여 넣지 말고, Claude Code 클라우드 환경 설정의 비밀값(환경 변수)으로 `MESHY_API_KEY` 이름으로 등록
3. 같은 설정의 네트워크 허용 도메인에 `api.meshy.ai` 와 `assets.meshy.ai` 추가
4. 새 세션을 열면 저장소의 `.mcp.json` 에 적힌 **Meshy 공식 MCP 서버**(`@meshy-ai/meshy-mcp-server`)가 연결됩니다

**만들기**: MCP로 Claude에게 맡기거나, 직접 스크립트를 실행합니다(크레딧이 듭니다).
```
node tools/meshy-generate.mjs students        # 학생 사진 → 3D 캐릭터 + 사람 뼈대 + 걷기 동작
node tools/meshy-generate.mjs relics          # 유물 7점 (assets/relics/ref/<이름>.jpg 가 있으면 그 사진 기준)
```
- 학생은 정면 사진 한 장으로도 만들어지지만, **옆·뒤 사진**(`assets/players/male_side.jpg`, `male_back.jpg` 등)을 함께 넣으면 여러 장 기반으로 더 정확해집니다.
- 유물은 실제 유물 사진을 `assets/relics/ref/` 에 넣으면 사진 기반으로, 없으면 유물 설명문으로 만듭니다.
- 결과: `assets/players/*.glb` + `models.json`, `assets/relics/*.glb` + `manifest.json`. 크기와 위치는 게임이 자동으로 맞춥니다.
- 지금은 친구 NPC(뼈대·걷기 동작 포함)와 손에 드는 유물에 적용됩니다. 내 그림자·내려다본 다리는 코드로 만든 모델을 씁니다.
- GLB는 용량이 커서 서버로 실행할 때(`index.html`)만 불러옵니다. 한 파일 실행본(`dist/bundong3d.html`)은 코드로 만든 모델을 씁니다.

**직접 GLB를 넣을 때** — 이름: `sword`(사인참사검) `mirror`(다뉴세문경) `censer`(금동대향로) `jade`(곡옥) `bomb`(비격진천뢰) `rocket`(신기전) `sundial`(앙부일구)
```json
// assets/relics/manifest.json
{ "censer": "censer.glb" }
// assets/players/models.json  (rotY: 모델이 뒤를 보면 3.14)
{ "male": { "model": "male.glb", "walk": "male_walk.glb", "height": 1.72, "rotY": 0 } }
```

## 알려진 한계

- 키보드·마우스용입니다(휴대폰·태블릿 터치 조작은 아직 없음).
- 본관은 1층만 들어갈 수 있습니다(2층 이상은 계단에서 출입 통제).
- 학교 배치는 참고 영상에 보이는 부분을 기준으로 재구성한 것으로, 실제 도면과 다를 수 있습니다.
