게시 메뉴가 없거나 Canva Code를 쓸 수 없어요

현재 계정의 기능 제공 상태와 학교·팀의 AI 설정을 먼저 확인하세요. 설치나 결제를 반복하지 않아도 됩니다. 6쪽에서 Gemini로 바꾸면 같은 주제로 새 퀴즈를 만들어 실습을 이어갈 수 있습니다.

Gemini Canvas 공식 안내 ↗
메모장에서 HTML 저장하기 / 404 화면 해결하기

Windows 메모장에 HTML 전체를 붙여 넣고 ‘다른 이름으로 저장’을 누르세요. 파일 이름은 index.html, 파일 형식은 ‘모든 파일’, 인코딩은 UTF-8로 정합니다. index.html.txt로 저장되지 않았는지 확인하세요. Mac 텍스트 편집기는 ‘일반 텍스트로 만들기’를 먼저 선택합니다.

코드 앞뒤의 백틱 3개는 넣지 마세요. 404가 나오면 올린 폴더 맨 위에 index.html이 있는지 확인하세요. React나 여러 파일로 된 프로젝트는 완성된 배포용 폴더가 필요합니다. 첫 실습은 HTML 파일 하나로 만들어 달라고 요청하세요.

수정 후에는 같은 사이트의 Deploys 화면에 수정한 폴더를 다시 올리세요. 새 사이트를 매번 만들지 않아도 됩니다.

Netlify Drop 열기 ↗

동쌤의 웹앱들도 이 방법으로 올렸어요. 주소가 내가 정한 이름.web.app으로 깔끔하고, 나중에 학생 답을 실시간으로 모으는 데이터베이스(Firestore)도 같은 곳에 붙일 수 있어요. 첫 실습은 정적 웹페이지만 올립니다. Firebase의 무료 요금제(Spark) 한도 안에서 진행하고, 결제가 필요한 기능은 추가하지 않습니다.

처음이라면, 같은 Codex·Claude Code 작업에서 배포를 요청하세요. 6쪽에서 파일을 만든 작업의 입력칸에 아래 문장을 붙여 넣으세요. 작업 폴더와 배포 대상을 확인하며 함께 진행할 수 있습니다. 계정 로그인과 권한 승인은 직접 마쳐야 할 수 있습니다.
이 작업 폴더의 웹앱을 Firebase Hosting에 배포해 주세요. 먼저 파일이 실제로 실행되는지 확인하고 배포할 프로젝트 ID를 알려 주세요. 기존의 다른 사이트는 바꾸지 말아 주세요. 로그인과 승인이 필요한 단계는 제가 직접 진행할 수 있게 안내해 주세요. 첫 실습은 무료 한도 안의 정적 웹사이트로만 배포하고, 완료 후 실제 접속 주소와 직접 확인한 내용을 알려 주세요.

아래는 직접 진행할 때의 순서입니다. AI와 진행하더라도 로그인 계정, 프로젝트 ID, index.html 위치를 함께 확인하세요.
