Firebase 설정이 비어 있어요

진행자 화면은 Firebase가 있어야 작동해요. firebase-config.js에 Firebase 웹 앱 설정값을 넣은 뒤 다시 배포해 주세요. 그 전까지 학습지는 각자의 기기 안에서만 작동해요.

계정은 진행자로 등록되어 있지 않아요. 등록된 계정으로 다시 로그인해 주세요.

수업방

100명 이상 연수 전, 진행자가 확인할 사항
  1. 연수 전에 실제 사용할 학교 계정과 PC에서 Canva Code 또는 Gemini Canvas가 열리는지 확인하세요. 설치가 제한된 PC는 무료 도구 실습으로 진행할 수 있습니다.
  2. 같은 인터넷 회선을 쓰는 100명 이상이 처음 입장하면 Firebase의 신규 계정 생성 제한에 걸릴 수 있습니다. 기본 제한은 IP 주소당 시간당 100개이며, 익명 로그인도 새 계정을 만듭니다. 연수 전에 Firebase 콘솔의 Authentication 설정에서 임시 할당량 증가를 예약하거나, 참가자가 사용할 기기와 브라우저로 입장을 미리 마치세요.
  3. Firebase 콘솔에서 Authentication과 Firestore 사용량을 확인하세요. 강사와 참가자 기기로 입장, 응답 전송, 작품 등록을 미리 점검하세요. 로컬 검증은 실제 학교망의 접속을 보장하지 않습니다.
  4. 입장이 제한되면 ‘수업방 없이 실습 계속하기’를 안내하세요. 작성 내용은 해당 브라우저에 저장되지만 진행자에게 전송되지는 않습니다. 완성한 작품 주소는 별도로 모아 주세요. AI 사용 한도에 도달하면 6쪽의 예제 HTML 파일로 점검 연습을 이어갈 수 있습니다.
