# 에듀파인 자동 품의 with Claude

교사가 **"기술 수업 롤링볼 재료로 우드락 450x450 10장, 장당 3천원"** 처럼 한두 줄만 적으면,
Claude가 품의서 초안을 만들고 → 크롬을 직접 조작해 **업무포털 인증서 로그인 → K-에듀파인 품의 작성·저장 → 결재요청(기안)** 까지 진행하는 프로그램입니다.

> 마우스 잡은 건 선생님이 아니라 **Claude** 입니다.

---

## 1. 시연 영상 분석 → 프로그램 동작

영상(43초)을 프레임 단위로 분석해 실제 화면 흐름을 그대로 절차서(`pumui/playbook.py`)로 옮겼습니다.

| 영상 단계 | 영상 속 화면 | 프로그램이 하는 일 |
|---|---|---|
| ① 인증서로 로그인 | 업무포털 → 「교육행정 전자서명 인증서 로그인」 → 인증서 선택창(하드디스크/이동식디스크…) | 버튼 클릭 → 본인 인증서 선택 → **암호는 프로그램이 직접 입력**(Claude에게 안 보임) → 확인 |
| ② 메인 화면 · 팝업 정리 | K-에듀파인 메인, 공지 팝업 | K-에듀파인 진입, 새 창 자동 전환, 공지 팝업 닫기 |
| ③ 품의목록 → 신규 작성 | 즐겨찾기 › 품의목록, [신규] | 학교회계 › 사업관리 › 사업담당 › 품의/정산 › 품의목록 → [신규] |
| ④ 제목 · 개요 입력 | *제목, *개요, 품의기본문구 유형, 요구일자/완료요구일자 | 초안의 제목·개요(금액 한글 표기 포함)·일자 입력 |
| ⑤ 예산(세부항목) 선택 | 「예산선택」 창: 부서·세부사업·세부항목·원가통계비목·선택·산출내역·예산잔액 | 초안의 예산 단서(예: 과학 교과활동 / 학습준비물 / 기술과실험실습재료비)와 맞는 행 체크 → 확인. 애매하면 선생님께 질문 |
| ⑥ 품목 입력 → 저장 | 품목내역 [행추가] → 내용·규격·수량·단위·예상단가, 요구금액 30,000 | 행추가·입력 → 요구금액 검증 → [저장] → 확인창 처리 |
| (영상 이후) 실제 기안 | [결재요청] → 결재정보 → 상신 | **선생님 최종 승인 후에만** 결재요청·상신 (승인 전에는 버튼 클릭 자체가 차단됨) |
| ⑦ 시연용 삭제 | 삭제완료 알림 | 연습 모드(모의 에듀파인)로 대체 — 실제 시스템에 테스트 문서를 남기지 않음 |

## 2. 구성

```
선생님 ──(한두 줄)──▶ [웹 화면 127.0.0.1:8765]
                         │ ① 초안 생성: Claude 구조화 출력 → 제목/개요/품목/예산단서/일자 (pumui/drafter.py)
                         │ ② 선생님이 확인·수정
                         ▼
                    [에이전트 루프] (pumui/agent.py)
                         │  Claude computer use(computer_toolset_20260801)
                         │  스크린샷 보고 → 클릭/입력/스크롤 지시
                         ▼
                    [브라우저 제어] Playwright + 실제 크롬/엣지 (pumui/browser.py)
                         │  · 'Claude' 커서 표시 (영상처럼)    · iframe 안까지 클릭 대상 판별
                         │  · 상신/결재요청 버튼 승인 전 차단  · alert/confirm 자동 처리
                         ▼
                    업무포털 · K-에듀파인
```

| 파일 | 역할 |
|---|---|
| `pumui/drafter.py` | 자연어 → `PumuiDraft`(제목·개요·품목·예산단서·일자) 구조화 출력 |
| `pumui/models.py` | 품의 데이터 구조, 합계·`금30,000원(금삼만원)` 표기, 개요 자동 작성 |
| `pumui/playbook.py` | 영상 기반 K-에듀파인 조작 절차서(시스템 프롬프트) |
| `pumui/agent.py` | Claude computer-use 루프 + 보조 도구(진행표시·암호입력·선생님 질문·최종승인·탭관리·완료) |
| `pumui/browser.py` | Playwright 조작, 안전장치(상신 버튼 가드), 커서 오버레이 |
| `pumui/server.py`, `pumui/static/index.html` | 선생님용 웹 화면 (실시간 화면·진행 단계·소요시간) |
| `pumui/cli.py` | 콘솔 모드 |
| `mock_edufine/` | **연습용 모의 업무포털·K-에듀파인** (영상 화면을 재현, 실제 시스템과 무관) |
| `tests/` | 모의 에듀파인 전 과정 E2E 테스트 + 단위 테스트 |

## 3. 설치 (Windows, 최초 1회)

1. [Python 3.10 이상](https://www.python.org/downloads/) 설치 (설치 화면에서 *Add python.exe to PATH* 체크)
2. 이 폴더에서 **`setup.bat`** 더블클릭 → 패키지 설치 후 메모장으로 `.env`가 열립니다.
3. `.env`에 입력:
   - `ANTHROPIC_API_KEY` — [Claude Console](https://console.anthropic.com)에서 발급
   - `PUMUI_REGION` — 소속 교육청 코드 (서울 `sen`, 경기 `goe`, 부산 `pen` …)
   - `PUMUI_CERT_PASSWORD` — (선택) 인증서 암호. 비워두면 로그인 때 직접 입력하라고 안내합니다.
   - `PUMUI_STOP_AT` — `submit`(결재요청까지, 상신 직전 승인) 또는 `save`(저장까지만)

> 업무용 PC에 K-에듀파인 접속에 필요한 보안 프로그램(인증서 모듈 등)이 이미 설치되어 있어야 합니다.
> 처음 실행 시 자동 실행된 크롬에서 보안 프로그램 설치 안내가 나오면 안내대로 설치해 주세요.

macOS/Linux: `./run.sh` (처음 한 번은 설치, 그다음부터 실행)

## 4. 사용법

**`run.bat`** 실행 → 브라우저에 `http://127.0.0.1:8765` 화면이 열립니다.

1. **품의 내용 입력** → [Claude로 품의 초안 만들기]
2. **초안 확인·수정** — 제목(300Byte 표시), 유형, 일자, 예산 단서, 품목, 개요. 노란 상자는 Claude가 추정한 값이니 꼭 확인하세요.
3. **[에듀파인에 자동 작성]** — 새 크롬 창이 열리고 Claude가 진행합니다. 오른쪽에 실시간 화면·단계(①~⑧)·소요시간이 표시됩니다.
   - 인증서 암호 직접 입력, 예산 행 선택 등이 필요하면 **"Claude가 선생님께 요청합니다"** 창이 뜹니다.
   - 저장 후 **결재요청(상신) 최종 승인** 창이 뜹니다. 크롬 화면을 확인하고 [승인하고 상신] 또는 [보류].

**처음엔 꼭 「연습 모드」로** 한 번 돌려 보세요. 영상과 같은 모양의 모의 에듀파인에서 전 과정을 안전하게 시험합니다.

콘솔 모드:
```bash
python -m pumui run "과학실 실험용 비커 500ml 20개 구입" --mock          # 연습 모드
python -m pumui run "우드락 10장 장당 3000원, 기술 수업" --stop-at save   # 실제, 저장까지만
python -m pumui draft "학년 협의회 다과비 8명 1인 6천원" -o draft.json     # 초안만
python -m pumui run --draft-file draft.json                             # 고친 초안으로 실행
```

이미 로그인해 둔 내 크롬을 그대로 쓰고 싶다면: 크롬을 `chrome.exe --remote-debugging-port=9222`로 실행하고
`.env`에 `PUMUI_CDP_URL=http://127.0.0.1:9222` 를 넣으세요.

## 5. 안전장치

- **상신 가드**: 승인 전에는 `결재요청`·`상신`·`기안` 버튼을 클릭하거나 Enter로 누르는 동작을 프로그램이 **물리적으로 차단**합니다
  (iframe 안쪽 요소까지 판별). "상신하시겠습니까?" 같은 확인창도 승인 전엔 자동 취소됩니다.
- **암호 비노출**: 인증서 암호는 `type_secret` 도구로 프로그램이 직접 키보드 입력합니다. Claude에게 전달되지 않고 로그에도 남지 않습니다.
- **추측 금지**: 데이터에 없는 값이나 애매한 예산 행은 선생님께 질문하도록 절차서에 명시했습니다.
- **기록**: 실행마다 `runs/날짜-시간/`에 초안·결과·단계별 스크린샷이 저장됩니다.
- **중단**: 웹 화면의 [중단] 버튼으로 언제든 멈출 수 있습니다.

## 6. 꼭 알아두실 점

- **정보보안**: 작업 중 화면 스크린샷이 Claude API(Anthropic)로 전송됩니다. 화면에 다른 문서·개인정보가 보일 수 있으니
  소속 교육청의 정보보안 지침(외부 AI 서비스 이용, 업무 자동화 허용 여부)을 먼저 확인하세요. 학교망에서 `api.anthropic.com` 접속이 막혀 있으면 동작하지 않습니다.
- **실제 화면 차이**: 시·도교육청·버전마다 메뉴 위치나 버튼 이름이 조금 다를 수 있습니다. Claude가 화면을 보고 판단하므로 대부분 적응하지만,
  막히면 선생님께 질문합니다. 자주 막히는 지점은 `pumui/playbook.py`의 절차서에 한 줄 추가하면 다음부터 더 정확해집니다.
- **키보드 보안 프로그램**: 일부 보안 모듈은 자동 입력을 막습니다. 이 경우 인증서 암호는 안내 창이 뜰 때 직접 입력하면 됩니다.
- **속도·비용**: 영상의 43초보다는 오래 걸릴 수 있습니다(보통 수 분). 기본 모델 `claude-opus-5-5` 기준 1회 대략 1~3달러 수준이며,
  실행 후 결과 상자에 예상 비용이 표시됩니다. `.env`의 `PUMUI_MODEL=claude-sonnet-5-5`로 비용을 낮출 수 있습니다.
- **대체 모델**: 안전 분류기가 요청을 거절하는 드문 경우를 위해 서버 측 대체 모델(`fallbacks: "default"`)을 켜 두었습니다. 끄려면 `PUMUI_FALLBACKS=off`.
- 최종 책임은 기안자에게 있습니다. 승인 창에서 크롬 화면의 값을 한 번 더 확인하세요.

## 7. 개발자용

```bash
pip install -r requirements.txt pytest
python -m pytest -q          # 모의 에듀파인 E2E + 단위 테스트 (API 키 불필요)
```

E2E 테스트는 "각본대로 움직이는 가짜 Claude"가 실제 Claude와 같은 형태의 computer toolset 호출을 보내
에이전트 루프 → Playwright → 모의 에듀파인 전 과정(로그인·팝업·신규·입력·예산·품목·저장·상신 차단·승인·상신)을 검증합니다.
크롬 경로를 지정하려면 `PUMUI_BROWSER_PATH`를 설정하세요.
